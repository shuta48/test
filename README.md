# Cursortest

お菓子メーカーのPR案件向けに作成した、業務整理用フォルダです。

## フォルダ構成

- `ナレッジ`
  - 自分の考え、アイデア、業界知識、日々のメモを蓄積
- `PR業務`
  - SNS運用、コンテンツ制作、競合リサーチを管理
- `営業`
  - クライアント対応、提案書作成、商談記録を管理
- `経理`
  - 売上管理、請求書作成、経費管理を管理

各フォルダ配下には以下を配置しています。

- `参考資料`: 外部情報や下調べ資料
- `成果物`: 提出・共有する確定版ファイル
- `CLAUDE.md`: 役割と運用ルール

## 運用ルール（共通）

- ファイル名に日付や版数を含める（例: `2026-05-28_提案メモ.md`、`企画書_v2.md`）
- 確定版は`成果物`へ集約する
- 出典のある情報は参照元を記載する
- 機密情報（鍵、認証情報、`.env`）は保存しない

## 運用テンプレート（追加済み）

- `ナレッジ/成果物/テンプレート_日記.md`
- `PR業務/成果物/テンプレート_SNS投稿企画.md`
- `営業/成果物/テンプレート_商談メモ.md`
- `経理/成果物/テンプレート_請求管理.md`

## Git運用

- デフォルトブランチ: `main`
- リモート: `origin` (`https://github.com/shuta48/test.git`)
- 不要ファイルは`.gitignore`で除外済み
